# omuso
_A cross-platform music client for self-hosted Navidrome servers using the OpenSubsonic API._

**Note:** This is a passion project that is very much a work in progress.

## What's the point of omuso?

The largest, non-goal driver for this project is my meshing of adoration for independent music ownership and the medium of audio media players.

While I know there are a lot of pre-existing music streaming tools, apps, and even Navidrome clients, none have fully scratched my exact desire for how I enjoy consuming music.

There are two primary (semi-opposing) goals for developing **omuso**:
1) I desire to make sense of the tangled wires behind streaming music players and learn all I can about the development of their different features.
2) I want to create a platform where I can explore alternative approaches to what has become the norm and test potentially peculiar alternatives.

While my current state of progress in Phase 1 is for modern feature parity, in Phase 2 I will aim to start exploring potential alternatives and designs.

## Roadmap
**Phase 1:** (Current state)
- Native Android support.
- Feature parity with modern music players.
  - [x] Server-authenticated login 
  - [x] Server-side search
  - [x] Native Android playback/control
  - [x] Media favoriting
  - [x] Album views
  - [ ] Artist views (actively in progress)
  - [ ] Alterable queue
  - [ ] Playlist support
  - [ ] Lyric support

**Phase 2:**
- Native iOS support.
- Custom feature/concept exploration.
- Visual revamp.

**Phase 3:**
- Browser/desktop support (via Tauri).
- Customization via CSS.
